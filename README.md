A single sentence pitching a ridiculous invention that fixes a tiny everyday
annoyance: a pocket defibrillator that shocks a dying biro back to life
mid-signature, so your name never trails off into a fading ghost line.

`main.ts` is a small Node 22 TypeScript program that writes exactly that
sentence to `/output/entry.txt`. It is deterministic and self-contained: it
reads nothing from secrets, the network, git history, or any file outside
this repository — the sentence is a string literal inside `main.ts`.

Run it with:

```sh
node main.ts
```
